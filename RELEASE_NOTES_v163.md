# ORION v163 — Institutional Runtime Closure

## Major changes
- Durable forecast/model/replay state owned by the control plane.
- Point-in-time provider ingestion guard and dataset coverage contract.
- Research Operating Coordinator bridges readiness into the production research factory.
- Persistent paper NAV observation ledger.
- Every intelligence run creates a deterministic time-machine snapshot.
- Replay duplicate-cycle protection.
- New API surfaces for research requirements, paper NAV, learning report and replay.
- UI exposes dataset contract, provider readiness, learning and replay telemetry without synthetic market data.
- Live trading remains structurally disabled.

## Explicit non-goals
- No live broker routing.
- No fabricated NSE/BSE prices, fundamentals or constituents.
- No blind self-training.
