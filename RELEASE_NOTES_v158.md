# ORION v158 — Autonomous Architecture Completion

v158 closes the restart-safe closed-loop operating layer around v157.

## Architecture

`Universe Scheduler → PIT/Data Quality → Evidence/Research → Decision Plane → Progressive Brain → Counterfactual/Scenarios → Portfolio/Risk → Allocation → Signal → Paper Execution → Forecast Outcome Resolution → Calibration/Champion-Challenger → Portfolio Attribution → Persistent Time-Machine Replay → Audit/Observability`

## Major additions

- Restart-safe forecast/outcome ledger.
- Durable champion/challenger model registry with bounded switch margin.
- Persistent time-machine snapshots and deterministic replay.
- Automatic horizon-aware forecast outcome resolution from supplied observations.
- Transparent portfolio return contribution attribution with residual reconciliation.
- Autonomous runtime coordinating research queueing, learning, attribution and replay.
- Deterministic universe scheduler with priority ordering and bounded chunks.
- Existing live-trading-off boundary preserved.

## Safety / integrity

- No outcomes are invented.
- No future information is admitted by the resolver.
- Model changes require observed outcomes and a material improvement margin.
- Replay validates snapshot hashes.
- Live brokerage execution remains disabled.
